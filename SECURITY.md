# Security

Please do not report security problems in public issues. Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/Recodive/hansho/security/advisories/new).

We aim to acknowledge a report within three working days and will keep you informed while we fix it. In scope: the hub,
the SDKs, and the protocol they implement (pairing, the message envelope, webhook signatures, the device API).

Supported versions: the latest hub release and the latest release of each SDK.
