# Contributing

Thanks for helping. Issues and pull requests are welcome; for anything larger than a fix, open an issue first so we
can agree on the approach before you spend time on it.

## Layout and checks

- `hub/`: Go. `cd hub && go vet ./... && go test ./... -count=1`.
- `sdk/<language>/`: each SDK's own test command is in [sdk/README.md](sdk/README.md#testing).
- `sdk/spec/openapi.json` is the contract of the hub's sender API and every SDK; see [sdk/README.md](sdk/README.md#adding-or-changing-an-operation) for how to change it.
- `sdk/spec/webhook-vectors.json` is generated by the hub (`HANSHO_GEN_VECTORS=1 go test ./internal/webhook -run SDKVectors`
  in `hub/`), so the SDKs verify exactly what the hub signs.
- `sdk/scripts/run-integration.sh` runs every SDK against a real hub, a stub relay and a fake device, all on
  127.0.0.1. CI runs it on every pull request.

## Releases

Maintainers release the hub with a `v<version>` tag (image `ghcr.io/recodive/hansho-hub` and a GitHub release) and
each SDK with an `sdk/<language>/v<version>` tag; see [sdk/RELEASING.md](sdk/RELEASING.md).
